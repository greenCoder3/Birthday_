# Surprise Website Master Template ❤️

A reusable, mobile-friendly HTML/CSS/JavaScript template for birthday, anniversary,
proposal, friendship, wedding, farewell or any other personalized surprise website.

## Folder structure

- `index.html` — page structure
- `style.css` — design and animations
- `config.js` — **the main file you edit for each new person/event**
- `script.js` — interactions and effects
- `assets/photo1.jpg` — replace with your photos
- `assets/photo2.jpg`
- `assets/photo3.jpg`
- `assets/music.mp3` — replace with your music

## Make a new website

1. Copy the whole folder.
2. Open `config.js`.
3. Change the name, occasion, messages, reasons and memories.
4. Put your photos/music in `assets/`.
5. Open `index.html` in a browser to test.
6. Upload the files to a GitHub repository.
7. Enable GitHub Pages from Settings → Pages.
8. Select the `main` branch and `/ (root)`.
9. Save and wait for the deployment.

## Important

Keep the website static: HTML, CSS, JS, images and audio. Do not put passwords,
API keys or other secrets in the repository.

GitHub Pages is public hosting, so anything you put in the published site can be
viewed by anyone who has the URL.
